Mouse-wheel run / walk / ride speed for Skyrim SE/AE (1.7.x included). Pure SKSE plugin: no ESP, no Papyrus, no MCM.

**Based on [Scrolling Speed - adjust running speed with mouse wheel](https://www.nexusmods.com/skyrim/mods/65570) by SirArindel**, whose permissions are: "You are free to use the resources in this mod as long as you share your mod with the same permissions." This mod is shared with the same permissions. Scrolling Speed NG no longer loads on 1.7.x and has no source available, so this is a new plugin built on the original's idea.

- Wheel changes the speed level (5 levels by default, slowest 18% of normal); modifier key + wheel zooms. The roles can be swapped.
- Optional zoom key (wheel always zooms while held), optional faster / slower keys, key picker for every key, on-screen speed note can be switched off.
- Horse follows the level while riding. The wheel is left alone in menus, dialogue and TFCam's free camera.
- Settings page in SKSE Menu Framework, or `Data/SKSE/Plugins/ScrollingSpeed2026.json`.
- Needs SKSE64, Address Library, SKSE Menu Framework (settings page). Press "Reset and remove all modifiers" in the menu before uninstalling.
